## Matching profile pictures

Character prompts use the same material palette. Generate each overhead batch first, then upload its three named source PNGs with the corresponding profiles/<class>-profile-prompt.txt. Use exact RGB bases and the five allowed shading tones in every matched view. Existing downloads can serve as geometry/identity references, but normalize both new overhead and portrait outputs to the strict source palette; retain the originals unchanged. Profile ZIPs are separate source deliveries; the current viewer/installer does not ingest them.
