## Locked registration contract

Every part uses the SAME full 1024×1024 source canvas, with at least 64px
transparent outer padding. Never crop or independently center individual parts.
Runtime canvases are 128×128 and source pivots divide by eight.
Anatomical left is screen-right in the north-facing proof; do not mirror limbs.

| right_leg | [464,568] | root | 11 |
| equipment | [600,512] | torso | 60 |

These are a provisional locked NEW-master template, not measurements from old
art. Show a pivot overlay and establish which anatomical attachment each point
represents. A single resize/translation may not align all joints; do not claim
it fixes registration without measuring. If the template and intended camera
cannot be reconciled, report that concrete conflict before changing the template.
Any proposed template revision must update contract, prompts, source metadata,
Python validation and tests consistently before decomposition.

Arms/legs need 10–15% hidden proximal overlap. Head owns hidden neck overlap;
torso owns the visible collar. Older head-kit prompts used body-owned neck and
must not be silently mixed. First proof is bald, beardless and without eyewear.
Equipment may be an empty transparent layer when absent.

right-arm, left-leg, right-leg and equipment with the same naming convention.

## Exact source palette

Matte material bases, integer sRGB:

| Material | RGB |
| --- | --- |
| Shirt | 146,147,148 |
| Trousers | 82,111,137 |
| Harness | 186,169,141 |
| Gear/boots | 52,58,64 |
| Accents | 227,165,46 |
| Display | 0,217,238 |
| Skin | 213,155,112 |
| Hair/beard | 112,67,34 |

Five shades per material: add -32, -16, 0, +16 or +32 to EACH channel,
clamping to 0..255. Outline RGB is 20,22,24. Matte interiors alpha255;
antialiased edges may vary alpha but retain owning material RGB. No baked
background or unrestricted gradients. Lenses, when eventually needed, are a
separate overlay: RGB200,210,220 alpha0..80; sparse highlights RGB240,244,248
alpha<=128. Verify against the current shared prompt module before implementation.

Assign pixels by material before shade quantization. Global nearest-color
quantization alone does not establish semantic mask correctness. Preserve
original shading evidence and provide masks/overlay previews for review.
Strict palette checks apply to sources; normalized Lanczos runtime pixels
may have interpolated colors.

   candidates. Produce a source-sized pivot overlay and an honest attachment

   Preserve originals and do not approve a master solely from file checks.

   masks, then palette-normalize. Deliver the master, masks and validation
   report. Obtain master review before generating all seven parts.
3. **Stage B decomposition:** use that SAME approved master to build seven
   registered full-canvas layers, reconstructing hidden overlap where needed.
   Keep silhouettes, equipment identity and palette consistent.
4. **Rig proof:** prepare together, inspect neutral composite and rotation
   extremes (arms ±12°, legs ±15°), preview WALK and readability at 22 world
   units. Show gaps, occlusion and alignment failures before activation.
5. **Reviewed activation / later expansion:** activate only after explicit
   review. Matched portraits, hair, beard, glasses and goggles are later
   extensions; they must share material channels and approved identity.

±10°, legs ±12°, torso bob 2 source pixels. Gameplay movement remains instant;
there is no authored gameplay WALK state or live animation loop. DOWN rotates
