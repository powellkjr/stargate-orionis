# Modular room visual kits — reconciliation and implementation plan

Recorded October 13, 2026. Source: [verbatim v2 handoff](offworld-modular-room-visual-kit-handoff-v2.md), supplied from Downloads.

The initial request was documentation and a resumable plan. The user subsequently authorized CT arithmetic corrections, provisional dimensions/registration and prompt-generation changes. Those are now implemented in the [provisional art contract](offworld-modular-room-visual-kit-contract.md) and dedicated room-kit prompt exporter. Renderer adoption remains separate; no authored game data, installed art or downloaded originals change. No final image generation is requested.

## New presentation design

The v2 handoff supersedes the fixed-door whole-room overlay approach for future modular room-kit authoring. Existing overlays remain legacy assets and working fallbacks; adoption is not implemented. This design adds no canonical Rooms, Theories, Patterns, Recipes, Services or gameplay rules.

- Each logical cell has a 3×3 presentation grid, assembled from CENTER, CORNER, SHARED, EDGE_NORMAL, EDGE_DOOR and EDGE_OPEN.
- A same-Stage neighbor selects EDGE_OPEN. An exterior edge with an exactly located Transition selects EDGE_DOOR; other exterior edges select EDGE_NORMAL.
- Two exterior edges meeting select CORNER; one exterior and one internal/open edge select SHARED; two internal/open edges draw neither. A door remains exterior for corner classification.
- Each kit has three complete coordinated families, v01/v02/v03: six pieces per family, 18 source assets total. One Stage chooses one family for all cells and pieces. Independent piece selection is forbidden.
- Default CENTER repeats the chosen family. Large central machinery stays a separate prop unless topology-independent. Runtime mission instances remain separate from baked presentation content.
- Modules preserve registration, seams, footprint, doorway clearance and rotation-tolerant direct-overhead lighting. EDGE_DOOR has centered clear passage; EDGE_OPEN has no blocking wall or furniture. SHARED terminates exterior content toward the open join.
- CT1/CT2/CT3 share neutral wall geometry. Tier identity comes from a continuous underlay through a transparent 5×24-unit running slot: amber, blue and purple respectively. No whole-wall recoloring, separate tier wall models or top/bottom door-light variants.
- Stage topology, authored Transitions and visibility remain authoritative. Art must not reveal hidden Reality or determine connectivity. Base physical rooms and their Core Sets keep their identities when joined.

6. **Adopt in presentation as a separate implementation step.** Reuse `joinedCellSides`/`surfaceGeometry` for cell topology and outer boundaries. Add a pure module resolver and SVG placement/layers for base floor → CT underlay → neutral module art → runtime door detail/instances/overlays. Resolve exact Transition edges, preserve fog, and retain legacy fallback. Start Offworld Stage composition; assess Room Sandbox adaptation separately without merging physical rooms or Core Sets.
7. **Select families deterministically.** Recommended convention: existing FNV-style hash of `seed:kitId:stageId`, modulo the sorted complete eligible family list. With exactly three families this is modulo 3. Persist/reconstruct the presentation seed so rerender, leave/return and reload retain selection. Incomplete/rejected families must not cause per-piece mixing. Define pool-version behavior explicitly; a changed eligibility list can change modulo selection.
8. **Validate each implemented step.** Prompt tests should assert six roles, three complete coordinated families, exact agreed geometry, orientation, alpha/registration, door/open restrictions, packaging and subject exclusions. Preparation tests should verify frame preservation and reject incomplete families. Presentation tests cover 1×1 with 0–4 doors (adjacent/opposite pairs), 1×2 shared edge and outer door, and 2×2 four internal joins, no central posts and exact outer-edge doors. Add ambiguous-transition, SHARED orientation, fog, full-Stage family stability and identical CT geometry tests. Review actual assembly visually; prompts and PNG checks do not prove art quality.
