# Authored dialogue and processing flows

Generated by `node tools/export-flows.mjs`. Do not edit diagrams by hand.

These diagrams include all authored content, including unported Unity branches.
Solid arrows show authored dialogue/order/effects; dotted arrows show prerequisites
or references. Prerequisites apply together. No automatic room routing is implied.

Each dialogue response has its own box containing speaker requirements, conditions,
text and effects. Processing diagrams show resolved archetype defaults and overrides.

## Regenerate and render

Game builds regenerate this directory. Snapshot export also regenerates it.
Run from the repository root in Git Bash:

```bash
node tools/export-flows.mjs
node tools/export-flows.mjs --check
node tools/export-flows.mjs --render --jar "$HOME/Downloads/plantuml-1.2024.6.jar"
```

To review a different authored mission:

```bash
node tools/export-flows.mjs --mission path/to/mission.json --out docs/generated/other-flows
```

Use `--archetypes`, `--items` or `--data-dir` for alternative source catalogs.
PNG rendering uses local Java/PlantUML; `PLANTUML_JAR` overrides jar discovery.
Builds render PNGs when that jar is available; PlantUML text generation is required.
Your `puml` alias works from a diagram subdirectory; the exporter renders all three
subdirectories in one invocation. Graphviz is needed for rectangle layouts.
