# Theory Library

## Status

**ACTIVE ARCHITECTURE**

Theory is the semantic content-generation layer for the game.

The governing rule is:

> Theory describes semantic truth and valid possibilities. Existing game systems determine how those possibilities execute.

Theory should enrich universal systems rather than create private subsystems.

Do not infer new universal systems from an individual Profession document.

If Profession authoring exposes a reusable universal rule, move that rule into the appropriate architecture document.
