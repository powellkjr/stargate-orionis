Stargate Orionis / Browser Prototypes

Simulation demos

Explore all six current prototypes. Launch missions, review authored drafts, configure the shared base and personnel, or inspect strategic map generation. Each demo below identifies its current scope and save behavior.

✦Playable

Offworld Mission Sandbox

Equip an expedition party, deploy into the Missing Operative benchmark, explore, work, negotiate and fight. Evacuate people and recover items with shared-base capacity checks.

Persistence: Recovery confirmation and reservation reset require the writable local server.

Room Sandbox

Place physical rooms, inspect base tiles, join and split compatible Room Groups, upgrade construction tiers, and generate procedural base layouts.

Persistence: Save shared base writes validated local JSON through the writable server.

Room Staffing Demo

Inspect joined-room staffing, functional tabs, storage compatibility and capacity. Place personnel, item and Theory references, and test persistent Receiving instances within the page session; process buttons are not executable.

Persistence: Receiving queues are session-only; reload restarts their simulation.

Open staffing demo→

World Map Simulator

Generate seeded Stargate networks and campaigns, inspect routes and Havens, test infrastructure failures, compare SGC Knowledge with debug Reality, and evaluate seeds in batches.

Persistence: Export debug snapshots and batch results; reproduce maps with their seed and settings.

Open world map→
☺Instrument

Character & Portrait Editor

Edit personnel portraits, character stats, Profession progression and configured Tools. Preview expertise and the appearance used by roster icons and Offworld map tokens.

Persistence: Shared appearance, stats, progression and Tool saves use the writable local server.

◇Author review

Mission Author

Compose deterministic source-backed mission drafts, review Stages, clues, interactions and recovery intent, inspect selection traces, and assess unresolved Finalizer readiness. Drafts are not deployed playable missions.

Persistence: Import/export Draft and trace JSON; no shared saves or live mission changes.
