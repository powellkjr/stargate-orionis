# Stargate Orionis

Strategy/base-management game design and browser simulator prototypes.

## Start here

- **[Repository map](REPO_MAP.md)** — compact navigation for developers, chats,
  Codex and coding agents: systems, fixtures, design authorities and tests.
- **[Agent instructions](AGENTS.md)** — working rules and architecture boundaries.
- **[Current task](CURRENT_TASK.md)** — Offworld progress and milestone history.
- **[Run the demos](demos/README.md)** — one launcher and writable/static limits.

From the repository root:

```bash
node demos/serve.mjs
```

Open `http://127.0.0.1:8001/demos/` for the demo hub. No npm install or build
step is required. See the repository map for focused test commands.
